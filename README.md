# 🚀 AI Startup Landing Page

A modern, high-performance landing page built with **React**, **Vite**, **Tailwind CSS**, and **GSAP**. This project was created as a client demo to showcase a premium UI/UX experience for AI startups and SaaS businesses, featuring responsive layouts, smooth animations, and clean component architecture.

## ✨ Features

* 🤖 Modern AI startup design
* 📱 Fully responsive across desktop, tablet, and mobile
* ⚡ Lightning-fast development with Vite
* 🎨 Beautiful UI built with Tailwind CSS
* 🎬 Smooth animations powered by GSAP
* 🧩 Reusable React components
* 🌈 Interactive hover and scroll effects
* 🖱️ Animated call-to-action sections
* 💡 Modern typography and layout
* 🚀 Optimized for performance
* 📈 SEO-friendly structure
* ♿ Accessible and user-friendly interface

---

## 🛠️ Tech Stack

* **React**
* **Vite**
* **Tailwind CSS**
* **JavaScript (ES6+)**
* **GSAP (GreenSock Animation Platform)**
* **React Hooks**

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ai-startup-landing-page.git
```

Navigate to the project directory:

```bash
cd ai-startup-landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
